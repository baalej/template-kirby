# Kirby & Privacy

Kirby's own statement on what data the CMS itself collects/transmits (primarily: license validation and the optional update check calling home to getkirby.com). Relevant when a client asks about GDPR/privacy compliance of the platform itself, as distinct from the site's own data handling (forms, analytics, cookies), which is the project's responsibility, not Kirby's.
