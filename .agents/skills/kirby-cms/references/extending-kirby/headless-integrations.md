# Headless & Integrations

Covers running Kirby purely as a content backend (no PHP templates rendering HTML) — content representations (`.json` templates, see `rendering-and-logic.md`) or the REST API (`extending-kirby/api.md`) feeding a separate frontend (static site generator, SPA, mobile app).

**Not this project's default mode** — this template assumes server-rendered PHP templates per AGENTS.md. Only relevant if a specific project explicitly needs a decoupled frontend; if so, note that decision in that project's own notes, since it changes several other defaults (no server-side BEM/CSS conventions apply the same way, for instance).
